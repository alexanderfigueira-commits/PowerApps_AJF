AV Central Deposit · PowerApps (Canvas) + SharePoint

Development Plan

1. Development Plan Document Overview

This document tracks the development of the AV Central Deposit app (Power Apps canvas app on SharePoint) in two phases. Phase 1 covers the request workflow in the app, page by page: Request Management, New Request, the four media tabs (Info, Metadata, Legal & Docs, Validations), Review, and the automations around them. Phase 2 covers archiving, audit and recovery, and reporting.

Task IDs come from the task matrix (P1-xx / P2-xx); "—" marks work added during development. Dates are delivery dates.

Open points

  • Decisions needed for P1-03, P1-06 (final status names), P1-09, P1-15, P1-19, P1-24, P1-34, P1-36.
  • Internal notes privacy: the Internal Notes on the Review screen use the same column as the requestor's per-media Notes, so they are not private. A separate InternalNotes column is needed if they must be admin-only.
  • Large audio files may exceed the attachment size limit; the app points users to the FTP path for those.
  • Print screens: rows on HomePrintScreen are not clickable in the current export (HP_Gallery.OnSelect missing).
